Place your `Euclid Circular A` webfont files here if you want the project to ship the font directly.

Supported filenames:

- `EuclidCircularA-Light.woff2`
- `EuclidCircularA-Light.woff`
- `EuclidCircularA-Regular.woff2`
- `EuclidCircularA-Regular.woff`
- `EuclidCircularA-Medium.woff2`
- `EuclidCircularA-Medium.woff`
- `EuclidCircularA-Semibold.woff2`
- `EuclidCircularA-Semibold.woff`
- `EuclidCircularA-Bold.woff2`
- `EuclidCircularA-Bold.woff`

The app already tries `local("Euclid Circular A")` first, so if the font is installed on your machine it will work immediately even without copying files here.
